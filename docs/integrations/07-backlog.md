# 07. Backlog: assistant integration tickets

IDs `AGT-nnn`. Effort in person-days [U estimates]. "Builder" is the gh- agent that implements; gh-security reviews every ticket marked (SEC-REV) and writes the tests listed. Prerequisite security tickets are in docs/security/06-backlog.md and are referenced by ID, not repeated. Totals: P0 20, P1 37.5, P2 29, P3 19, P4 24 = 129.5 days (wallet AGT-035 is optional, +8).

Conventions for all tickets: no photo, address, email, phone or free text in any event, log or audit row (docs/data ground rules); synthetic test data only; tests in Vitest, Playwright for flows; tool annotations explicit; money in cents; every write tool takes an idempotency key.
