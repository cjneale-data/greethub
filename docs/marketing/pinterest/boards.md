## General board SEO notes

1. Name and description carry the keywords; the cover carries no keywords the name does not already have.
2. Each pin goes to one board only at first. Re-pinning a pin to a second board later is allowed, but not before week 4.
3. Alt text: write a one-sentence description of the image for every pin (what a screen reader would say), not a keyword list.
4. Pin titles and descriptions are in pins.md, written for people first; no hashtag blocks (2 or 3 at most).
5. Do not mention "invite-only", waitlist or availability in board descriptions until the CMO confirms the wording (social review section 3, week 4 note).
6. Keyword choices here come from the playbook and the occasion-page slugs, not from search data. No Pinterest Trends, Keyword Planner or ranking data was available: label every keyword as a guess until measured.
